# Canonical balance scale and scale-free signed obstruction

Checkpoint: `282533f8`.

The signed 243-slot first-monomial obstruction can now be tested without
supplying a balance scale, provided E0 > 0 and E3 > 0. The explicit choice
is λ = (E0/E3)^(1/6), a positive real sixth root.

The committed sharp coefficient-one interpolation gives the balanced bound
`E0 + λ² E1 + λ⁴ E2 + λ⁶ E3 ≤ 4 E0`.

Consequently, a proposed uniform coefficient C ≥ 0 forces
`M^12 ≤ (2C)^12 D^12 E0^5 E3` for every solenoidal profile with positive
endpoint energies. If D > 0, this also gives the dimensionless quotient
`M^12 / (D^12 E0^5 E3) ≤ (2C)^12`.

An actual positive balanced excess rules out that C. No profile exhibiting
strict excess is constructed here. E3 > 0 and D > 0 are explicitly assumed
where needed; there is no implicit proof of those facts for nonzero fields.
